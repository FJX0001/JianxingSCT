# BCC字幕转SRT格式转换工具

一个功能强大的Web应用程序，用于将Bilibili的BCC字幕格式转换为标准的SRT字幕格式。完全在浏览器本地处理，无需上传到服务器，确保用户数据隐私安全。

## 🌟 主要功能

- **支持.bcc文件格式**：专门为Bilibili的BCC字幕文件优化
- **批量处理模式**：支持一次性转换多个字幕文件
- **本地处理**：所有转换在浏览器中完成，无需上传
- **自动下载**：转换完成后自动下载并保留原始文件名
- **拖放支持**：支持拖放文件上传
- **示例预览**：提供BCC和SRT格式示例
- **进度显示**：批量转换时显示详细进度
- **键盘快捷键**：支持Ctrl+Enter转换、Ctrl+D下载等快捷键

## 🔧 使用方法

### 单文件转换
1. 点击上传区域或拖拽BCC文件到指定区域
2. 点击"转换字幕格式"按钮
3. 转换完成后点击"下载SRT文件"

### 批量转换
1. 开启"批量处理模式"开关
2. 选择多个BCC文件（支持拖拽）
3. 开始转换，查看实时进度
4. 转换完成后下载ZIP压缩包

### 支持的文件格式
- `.bcc` - Bilibili字幕文件
- `.json` - JSON格式的BCC字幕
- `.txt` - 包含BCC字幕内容的文本文件

## ⚠️ 注意事项

### Windows安全警告
批量下载ZIP文件时，Windows可能会显示安全警告。这是正常的系统安全机制。如需解除：
1. 右键点击下载的ZIP文件
2. 选择"属性"
3. 在常规选项卡底部，找到"安全"部分
4. 勾选"解除锁定"
5. 点击"确定"即可正常解压

### 文件格式说明
- BCC是Bilibili专有的字幕格式
- SRT是通用的字幕格式，兼容大多数视频播放器
- 转换过程不会修改原始文件内容
